# Earnd

Earn your leisure screen time by doing the boring things first. Earnd is a local-first, offline
Android app (no account, no network, no analytics) for people with ADHD or executive dysfunction:
habits and tasks earn minutes, and leisure apps stay locked until you spend them.

- Requirements: [REQUIREMENTS.md](REQUIREMENTS.md)
- Architecture: [ARCHITECTURE.md](ARCHITECTURE.md)

## Build

```sh
./gradlew assembleDebug
```
Requires JDK 17 and the Android SDK (API 34). minSdk 29.
